PawGPT Sanctuary 🐾
PawGPT Sanctuary is a full-stack pet wellness and care management web application built with Python (Flask), HTML, CSS, and JavaScript. It serves as a centralized dashboard for pet owners to monitor their pet's daily health, nutrition, medical records, and milestones.

🚀 Features
Daily Care & Trackers: Log meals, track hydration goals, and time daily walks or exercise.

Health Triage & AI Vet: Smart symptom checker providing risk evaluations and instant guidance.

Nutrition Calculator: Calculate precise daily calorie recommendations based on pet weight, alongside safe/toxic food reference guides.

Medical Records & Scrapbook: Keep organized tabs on vaccinations, medications, and capture memories in a digital journal.

Customization: Fully responsive UI with profile management and dark/light mode support.

🛠️ Built With
Backend: Python, Flask, Jinja templates

Frontend: HTML5, CSS3, JavaScript
